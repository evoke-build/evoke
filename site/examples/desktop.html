Run everyday Mac tasks from the terminal, in plain words.

Type "set the volume to 40 percent" in your terminal, and evoke sets it. A reflex is a small program you install and ask for in your words. Thirteen reflexes for everyday Mac tasks install with one line. This example runs today on a Mac, and every file is on GitHub.

The request and the result

01

Three sentences, three outcomes.

A volume change runs at once. A less certain request asks first, and can keep your phrase as an example. A restart asks every time.

~rantaughtdeclined
$ evoke "restart the computer" power action="restart" · destructive · weakest: route 0.97 Really restart now? [y]es [n]o [t]each > n [2]
  1. 1Sure enough, so it ran. «40 percent» is a number read from your sentence and checked against the range 0 to 100. The least sure answer was 0.93, and a change runs without a question at 0.8 or above.
  2. 2«kill» meant off, but only at 0.72. Under 0.8, so evoke asked first. Typing t, for teach, saved your phrase as an example in a file of yours, then ran.
  3. 3Sure at 0.97, and it still asked. Its author marked power destructive, so it asks every time. No number and no flag skips that question. [2] means you answered no.

Every line is from a session in evoke's tests, which run on every change. The classifier's numbers in it come from a file written for the test, so yours will differ. How sure evoke must be to run →

Inside one reflex

03

A reflex is a manifest, and usually a short program.

This is volume. The manifest says what it does and what to ask you. The program runs one AppleScript command. Ten others are built the same way. open and trash are a manifest alone, which names a program the Mac already has.

volume/reflex.tomlthe collection's
reflex = 1

description = """
Set the output volume.
A percentage of the maximum; 0 is silent."""

not_for = ["muting and unmuting", "screen brightness", "one app's volume"]
tags    = ["sound"]
effect  = "write"
confirm = "Set the volume to {level}?"
run     = "volume.mts"

[args.level]
ask   = "How loud, in percent?"
pick  = "number"
range = [0, 100]

[examples]
"set the volume to 40 percent" = { level = "40 percent" }
"volume 15"                    = { level = "15" }
"turn the sound up to 80"      = { level = "80" }

[tests]
"make it 100 percent loud"   = { level = "100 percent" }
"turn the volume down a bit" = { level = false }
"mute the sound"             = false
"set the brightness to 50"   = false
volume/volume.mtsthe collection's
// Set the output volume through AppleScript: `set volume output volume <0–100>`.
import { execFile } from "node:child_process"
import { promisify } from "node:util"
import type { Reflex } from "./reflex.d.ts"

const exec = promisify(execFile)

export default (async ({ level }, { signal }) => {
  const percent = Math.round(level)
  // The one value written into AppleScript source: an integer, so it can only ever be digits.
  if (!Number.isInteger(percent)) throw new Error(`level ${level} is not a number`)
  if (process.platform !== "darwin") throw new Error("runs on macOS only")
  try {
    await exec("osascript", ["-e", `set volume output volume ${percent}`], { signal })
  } catch (error) {
    if (signal.aborted) throw signal.reason
    throw new Error(said(error) ?? "the volume did not change")
  }
  return `volume ${percent}%`
}) satisfies Reflex

/** What a failed command said on stderr, when it said anything; else nothing, and the caller's own words stand. */
function said(error: unknown): string | undefined {
  const text = typeof error === "object" && error !== null && "stderr" in error ? error.stderr : undefined
  return typeof text === "string" && text.trim() !== "" ? text.trim() : undefined
}
  1. 1The manifest is how you ask for it. A description, what it is not for, one input read as a number from 0 to 100, and example sentences.
  2. 2The program checks the platform first. On another system it stops at once and says it runs on macOS only. On a Mac it runs osascript and returns one line.
  3. 3Every file is on GitHub. The collection is MIT-licensed, so you can copy a script into a reflex of your own.

One boundary

04

A value outside its range never reaches the program.

The manifest gives the volume a range of 0 to 100. Your sentence chooses the value. evoke checks it against the range before the program sees it.

evoke
$ evoke "set the volume to 150 percent"
  How loud, in percent?  150 percent is outside 0–100  > 40
  volume level="40"  0.93

evoke asked the input's own question, with the reason on the same line. Your answer was checked the same way, then volume ran with 40. evoke guarantees that every value is one the reflex allows. It cannot guarantee that it read you right, which is why a bar decides what runs without a question. When evoke asks for a value, in the manual →

Set it up

05

Set it up on your Mac, from nothing to your first sentence.

Seven steps in your terminal. Every output line below comes from a session in evoke's tests. If a step stops, the line it prints ends with the command that fixes it. Each stop and its fix, on Get started →

  • macOSThe collection's programs are for a Mac. evoke itself also runs on Linux.
  • Node 24 or newerEleven of the thirteen reflexes run a JavaScript file.
  • gitevoke add fetches the collection from GitHub, at its newest version.
  • A key from TypeSafe AIFor Jev, the classifier that reads your sentences. TypeSafe AI bills each request to your key.
  • Your words, for three reflexesA folder, a site and a notes file. Optional, and one line each.

  1. Install evoke

    The script downloads the release built for your Mac, checks it against the release's checksums, and puts evoke in ~/.local/bin. If it prints a line that begins «add it to your PATH», run the command on that line first.

    curl -fsSL https://evoke.build/install.sh | sh

  2. Give evoke a key

    The classifier that reads each sentence is Jev, TypeSafe AI's model. Without a key, your first sentence stops and names the one it needs. [3] means evoke needs something from you.

    evoke
    $ evoke "lock the screen"
  jev needs TYPESAFE_API_KEY, a key from typesafe.ai  →  export TYPESAFE_API_KEY=<value>
[3]

    Get a key from TypeSafe AI, then export it. evoke reads it from your shell when it decides, and never writes it to a file. Each decision is one request, billed to your key, and a sentence you repeat is answered from a local cache.

    export TYPESAFE_API_KEY=<value>

  3. Have Node 24 or newer

    Eleven reflexes run a JavaScript file, so evoke add looks for node on your PATH and records where it is. Install Node 24 or newer from nodejs.org first. If you install it later, evoke sync records it.

  4. Install the collection

    Each row names a reflex, where it came from and at which version, its effect, and what it runs. Your rows show the collection's newest version. No code runs while it installs.

  5. Give three reflexes your words

    The inactive lines above each end with the command that fixes them. In the first line, desktop is your word and «The desktop.» its meaning, which the classifier reads. The path goes only to the reflex. A bare file name for note lands in your home folder.

    evoke
    $ evoke vocab places add desktop "The desktop." --value /Users/you/Desktop
+ vocab/places.toml  desktop = { what = "The desktop.", value = "/Users/you/Desktop" }
$ evoke config note file notes.txt
+ evoke.toml  [config.note] file = "notes.txt"

    For visit, add a site the same way:

    evoke vocab sites add github "GitHub." --value https://github.com

  6. Look at a decision before it runs

    evoke try decides and runs nothing. It shows the ranking of the reflexes, the answer for each input, how well each one fits, and what would happen: here, 0.72 is under 0.8, so it would ask first.

  7. Type your first sentence

    The indented line is evoke's own: the call it chose, and how sure it was. The last line is the reflex's result.

    evoke
