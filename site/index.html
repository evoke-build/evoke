A reflex

01

The author writes the manifest. You add your words. Jev decides.

Every line below is what the terminal shows.

lights/reflex.tomlthe author's
reflex = 1

description = """
Turn the lights in one room on, off, or dim them.
Ceiling and lamp lights only."""
not_for = [
  "colour scenes and schedules",
  "asking whether a light is on",
]
effect  = "write"

run     = "lights.mts"

[args.room]        # the options are the user's words
ask   = "Which room?"
vocab = "rooms"

[args.state]       # the options are the author's
ask         = "What should the lights do?"
options.on  = "Switch on."
options.off = "Switch off."
options.dim = "Lower the brightness without switching off."

[args.brightness]  # the value is a span of the input
ask      = "How bright, in percent?"
pick     = "number"
range    = [1, 100]
optional = true

[examples]         # sent to the classifier
"turn on the kitchen lights" = { state = "on" }
"dim the den to 30 percent"  = { state = "dim", brightness = "30 percent" }

The idea

02

Language as the interface. Without the generation.

The text box promised: say it, and it happens. So far, that meant a model writing on your behalf. evoke takes the other path.

Generation
Reflex
A model writes on your behalf.
A classifier picks a small program.
Different every time.
The same program, every time.
Can make anything up.
Can only choose: an option, your word, or a piece of what you typed.
Has to be trusted.
Can be checked. A closed question, and a number for how sure.
Slow, and priced by the word.
A fraction of a second, for almost nothing.
The next layer of software is not a bigger model that writes more. It is small programs, described well, chosen by reflex. A sentence can choose a call. It cannot invent one.

One decision

03

Three steps. Every judgment on the table.

Every manifest becomes questions. Jev answers them all at once. The weakest answer decides.

  1. 01DecideOne request asks everything: which reflex, which values, how well it fits.
  2. 02GateThe weakest answer is the confidence. Each effect has its bar.
  3. 03RunThe program runs with its arguments and a deadline. One line comes back.
evoke
$ evoke try "kill the lights"
  lights 0.90 · none 0.06 · timer 0.02 · volume 0.02
  room   unstated 0.75 · den 0.20 · office 0.05
  state  off 0.58 · on 0.30 · dim 0.10 · unstated 0.02
  fits   lights 0.70 · timer 0.05 · volume 0.05

$ evoke try "kill the lights in the den"

Three words moved the weakest answer from 0.58 to 0.85. An ask became a run.

The classifier

04

Jev decides.

TypeSafe AI's System One model. A classifier: typed decisions, calibrated probabilities, no text.

Asks
Closed questions. Which of these? Was it said? How well does it fit?
Answers
A calibrated probability per option. evoke reads numbers, never prose.
Generates
Nothing. Not one word.
Knows
Only the manifest's wording, sent with each request. No training, no weights.
Tuned by
A changed description or a new example. The next decision reads it.
Replaceable
Jev is the first adapter. The core names no engine.
In tests
A recorded adapter replays real answers. Offline, byte for byte.

A generating model has to be trusted. A classifier can be checked.

The question was closed. The options were yours. The number says how sure it was.

Wording is the tuning.

An overlay is your wording for one reflex. No update ever rewrites it.

Inside your app

07
app.ts
import { load, reflex } from "@evoke-build/evoke"
import { jev } from "@evoke-build/evoke/jev"

const timer = reflex({
  description: "Start a countdown timer.",
  effect: "write",
  confirm: "Start a {duration} timer?",
  args: {
    duration: { ask: "How long?", pick: "duration" },
  },
  examples: {
    "timer for ten minutes": { duration: "ten minutes" },
  },
}, async ({ duration }) => {   // duration: number, typed from the manifest
  setTimeout(() => console.log("ring"), duration * 1000)
  return `ringing in ${duration} s`
})

const project = await load({
  reflexes: { timer },
  adapter: jev(),
})
const handled = await project.handle("timer for ten minutes", {
  confirm: async d => true,
  ask: async d => ({ duration: "10 minutes" }),
})

The first hour is one file.

A reflex as code. A project with nothing on disk. The whole loop in one call.

  • The argument types come from the manifest.
  • A Decision narrows by outcome, then by reflex.
  • Each tenant gets its own vocabulary. Tests replay recorded answers, offline.

The ecosystem

08

Publishing is a git tag.

No accounts. No upload. A repository is a collection, a tag is a version, and the lock pins the content.

  1. 01Writeevoke new gives you three files that already work. evoke check says what the next tag must be.
  2. 02PublishTag it. Tags never change. A fix is a new tag.
  3. 03InstallFetched, checked against what is already installed, pinned by content. No code runs.
evoke
$ evoke new hello
+ hello/reflex.toml
+ hello/hello.mts
+ hello/reflex.d.ts
$ cd hello && evoke check
  hello  read  runs hello.mts
$ git tag v1.0.0 && git push --tags
$ evoke add you/hello
+ hello  you/hello 1.0.0  read  runs hello.mts

The first-party collection, evoke-build/reflexes, is thirteen reflexes for what a Mac does at a word.

Security

09

What a sentence can and cannot do.

A fetched reflex runs as you. add and update are where you decide to trust it. Around that, six promises hold.

  • State is only the sentence.Jev sees your input and the manifests' questions. Nothing else of yours.
  • Text can choose a call, never invent a value.An option, your word, or a checked piece of the input.
  • A destructive reflex always confirms.There is no --yes.
  • No code runs at install time.add reads a manifest and writes files. A program runs only at a decision.
  • Trust binds to content.Tag, commit and hash in the lock. A tag that moved is refused.
  • Prompts cannot be repainted.Control characters and bidi overrides are refused in every string.

Start

10

Install

One small binary on macOS and Linux. Node next to it, for reflexes written in JavaScript.

The CLI

Fetches the release for your machine, checks its digest, and puts evoke in ~/.local/bin.

curl -fsSL https://evoke.build/install.sh | sh

The SDK

Node 24 or newer, ES modules, no dependencies. The core ships inside as WebAssembly.

npm install @evoke-build/evoke

Then the first ten minutes: your key, the first-party reflexes, your first lesson. Other ways, mise and from source, are on the install page.
