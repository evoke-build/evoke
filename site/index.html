Install abilities. Connect them with a sentence.

evoke lets you call small programs in your own words. Compatible ones connect into a workflow. Each ability comes with a description and its input rules. It can also declare outputs that a later step can use.

Get started

Free and open source. A live sentence needs a key for the classifier, an online service that reads your words. The classifier's provider bills that use.

A reflex

01

An ability comes with a way to ask for it.

The mail ability from the walkthrough is a small program with a manifest. The manifest says what it does, what it is not for, and what to ask you when something is missing. This package is called a reflex.

mail/reflex.tomlby the author
reflex = 1

description = """
Start an email in your mail app.
To one address, with an optional subject; nothing goes out until you press send."""

not_for = ["reading or searching mail", "chat and text messages"]
effect  = "write"
confirm = "Write to {to}?"
run     = "mail.mts"

[args.to]
ask  = "To which address?"
pick = "email"

[args.subject]
ask      = "What is the subject?"
pick     = "quoted"
optional = true

[examples]
"email ana@example.com"                   = { to = "ana@example.com" }
'write to sam@example.com about "friday"' = { to = "sam@example.com", subject = "friday" }
description
What it does, in plain words. The classifier reads this to pick the reflex you mean.
not_for
What it does not do. Naming the near misses keeps a similar request from landing here.
[args.to] · [args.subject]
What it needs from you. An email address is taken from your sentence, word for word. The subject is optional.
effect
How careful to be. A write changes something you can undo. It runs on its own only when evoke is sure enough.
[examples]
Sentences that teach. You can add your own, and they stay in a file of yours.

The contact reflex adds one more table, [yields] email = "email". It declares what its result holds. That is what the walkthrough connected.

Your words

02

Your team's words belong here.

A reflex ships its wording. You keep the last word. Your names and your phrases live in files you own, and an update never touches them.

Decisions

03

See when it runs, and when it asks.

Every decision prints the call it chose and how sure it is. When something is missing or uncertain, it asks. An action that cannot be undone always asks.

ran
$ evoke "set the volume to 40 percent"
  volume level="40 percent"  0.93
volume 40%

Sure enough, so it ran. The number is the confidence. It is the weakest of the answers to the questions evoke asked.

asked
$ evoke "set the volume to 150 percent"
  How loud, in percent?  150 percent is outside 0–100  > 40
  volume level="40"  0.93
volume 40%

The value was out of range, so it asked. A sentence can choose a value. It can never invent one.

confirmed
$ evoke "restart the computer"
  power action="restart" · destructive · weakest: action 0.97
  Really restart now?  [y]es [n]o [t]each > n
[2]

Destructive, so it asked. Even at 0.97. There is no flag that skips the question. [2] is the exit code for a no.

A reflex that only reads runs on its own from a confidence of 0.6. One that writes needs 0.8. You can move these bars in a file you own. Explore the decisions →

Your own

05

Bring a capability of your own.

A function, a script or a command you already have can become a reflex. You write the program. The manifest describes it.

hello/reflex.tomlwritten by evoke new
reflex = 1

description = """
Say hello to someone.
A greeting with the name given, printed back."""
not_for = ["saying goodbye"]
effect  = "read"
confirm = "Say hello to {who}?"
run     = "hello.mts"

[args.who]
ask  = "Who should be greeted?"
pick = "quoted"

[examples]
'say hello to "Ada"' = { who = "Ada" }
'greet "Grace"'      = { who = "Grace" }
hello/hello.mtsyour code
import type { Reflex } from "./reflex.d.ts"

export default (async ({ who }) => `Hello, ${who}!`) satisfies Reflex

evoke new hello writes three files that already work. The manifest is the description. The body is your code, and it can call anything you already have.

  • The body receives typed arguments. Here who is a string, taken from the quotes.
  • The effect is your claim about it. A read, a write, or something that cannot be undone.
  • evoke check points at any line to fix and keeps the types beside the body current.

Start

06

Run your first reflex.

Ten minutes from an empty machine to a first result. Pick your terminal, or your app.

In your terminal

One small binary for macOS and Linux. Then the Mac collection, and one sentence.

curl -fsSL https://evoke.build/install.sh | sh
evoke add evoke-build/reflexes
evoke "lock the screen"

The first result is one line: locked. You need a classifier key first, and the guide says where it comes from.

In your app

The same decisions inside a Node application, over the same core.

npm install @evoke-build/evoke

One file holds a reflex written as code and the whole loop in one call. The SDK manual's first hour is six things to learn, in order.
