The idea

Language as the interface, without the generation.

For forty years software has waited to be operated: a menu, a flag, a form, a click in the right place. The text box promised something else — say it, and it happens — and paid for it with generation: a model writing on your behalf, differently each time, at a price and a pace no one could budget.

evoke takes the other path. It never asks a model to write. It asks a classifier a closed question — which of these programs, which of these values, was this even stated? — and Jev answers each with a calibrated probability, in a fraction of a second, for almost nothing. What runs is always a small program someone wrote and you installed, with arguments that are always one of the author's options, one of your own words, or a span of what you typed.

That is a reflex: the shortest path from a sentence to an action, with nothing made up along the way. Wording becomes the interface. Git becomes the registry. Confidence — not a prompt — decides what may run without asking.

The next layer of software is not a bigger model that writes more. It is small programs, described well, chosen by reflex. A sentence can choose a call. It cannot invent one.

One decision

Three steps, and every judgment on the table.

Every active reflex's manifest becomes questions. Jev answers them all at once; the gate reads the weakest answer; the body runs — or you are asked first. evoke try shows the whole thing.

01 · DECIDE

Which reflex, which values

One request carries the route, each argument of each reflex — with "unstated" among its options — and whether each reflex fits. Each comes back as a probability.

02 · GATE

The weakest answer rules

Confidence is the lowest of them. Against the floor for the winner's effect it settles the outcome: run, confirm, ask, or abstain. A destructive reflex always confirms.

03 · RUN

A small program, a scrubbed room

The body runs with its arguments, five environment variables, and a deadline shared with the answer; its one line of text comes back.

$ evoke try "kill the lights in the den"
  lights 0.91 · none 0.06 · timer 0.02 · volume 0.01

The classifier

Jev decides.

Jev is TypeSafe AI's System One model: a classifier that returns typed decisions with calibrated probabilities and generates no text. It takes no fine-tuning. Everything it knows about a reflex arrives in the request, from the reflex's own wording — its description, what it is not for, its examples.

evoke asks it every question of a decision in one pass and reads the answers as probabilities, never as prose. Where a generating model would have to be trusted, a classifier can be checked: the question was closed, the options were yours, and the number says how sure it was.

Jev is the first adapter, not the only possible one. The core names no engine; an adapter is a small mapping from questions to a request and from a response to answers, and a project names the one it uses in a file you own.

  • Closed questions, calibrated answers. Which of these? Was it stated? How well does this fit?
  • Nothing generated. A value is an option, one of your words, or a span of your input — never a model's invention.
  • Wording is the tuning. Change a description, add an example, and the next decision reads it. No training run, no weights.
  • Pluggable. Two question types cross the adapter boundary; anything that answers them can decide.
  • Reproducible in tests. A recorded adapter replays real answers, offline, byte for byte.

Getting started →

The unit

The manifest is the product.

A reflex is a directory: a manifest and the file it runs. The manifest says what the reflex does, what it is not for, what it asks, and what it runs. Its wording is the whole model — one line is documentation, tuning, test and customization at once.

The author owns the contract: what runs, the arguments, their options. Everything else is wording you may override in a file of your own, which no update ever touches. Teach it a phrase and it lands there, as one line.

Write a reflex in ten minutes → 
# hello/reflex.toml
reflex = 1

description = """
Say hello to someone.
A greeting with the name given, printed back."""
not_for = ["saying goodbye"]
effect  = "read"
confirm = "Say hello to {who}?"
run     = "hello.mts"

[args.who]
ask  = "Who should be greeted?"
pick = "quoted"

[examples]
'say hello to "Ada"' = { who = "Ada" }

# overlays/hello.toml — yours, one line, taught or typed
[examples]
'wave at "Grace"' = { who = "Grace" }
import { load, reflex } from "@evoke-build/evoke"
import { jev } from "@evoke-build/evoke/jev"

const timer = reflex({
  description: "Start a countdown timer.",
  effect: "write",
  confirm: "Start a {duration} timer?",
  args: {
    duration: { ask: "How long?", pick: "duration" },
  },
  examples: {
    "timer for ten minutes": { duration: "ten minutes" },
  },
}, async ({ duration }) => {   // duration: number
  setTimeout(() => console.log("ring"), duration * 1000)
  return `ringing in ${duration} s`
})

const project = await load({
  reflexes: { timer },
  adapter: jev(),
})
const handled = await project.handle("timer for ten minutes", {
  confirm: async d => true,
  ask: async d => ({ duration: "10 minutes" }),
})

Inside your app

The first hour is one file.

A reflex handed as code, a project with nothing on disk, and the whole loop in one call: decide, ask until nothing is missing, confirm, run. The body's argument types are inferred from the manifest literal; a Decision is a union you narrow by outcome, then by reflex.

Beside a real project, evoke add writes the lock and a .d.ts that types every installed reflex. Each tenant gets its own vocabulary and its own plan; a recorded adapter makes every test offline and deterministic.

The ecosystem

Publishing is a git tag.

No accounts, no upload, no registry to keep alive. A repository is a collection; a tag is a version; content is what the lock pins. The first-party collection is thirteen reflexes for what a Mac does at a word.

$ evoke new hello
+ hello/reflex.toml
+ hello/hello.mts
+ hello/reflex.d.ts

Write

Three files from a template that already works; evoke check keeps the manifest honest and types the body.

$ git tag v1.0.0 && git push --tags
→ published

Publish

Tags are immutable versions. evoke check diffs the contract against the last tag and says what the next one must be.

$ evoke add you/hello
+ hello  you/hello 1.0.0  read  runs hello.mts

Install

Fetched, linted, tested against the reflexes already there for phrases it would steal, pinned by content. No code runs.

Security

What a sentence can and cannot do.

A fetched reflex runs as you; add and update are the trust decisions. Around them, these hold.

  • State is only the sentence.The classifier sees your input and the questions built from installed manifests — nothing else of yours.
  • Injected text can choose a call. It can never mint a value.Every argument is an author's option, one of your words, or a checked span of the input.
  • A destructive reflex always confirms.There is no --yes. Unattended use is a threshold in a file you own and trust.
  • No code runs at install time.add fetches a tree, reads a manifest, lints it, and writes files. A body runs only at a decision.
  • Trust binds to content.The lock pins tag, commit and hash; the store is re-hashed at every start; a tag that moved is refused.
  • Prompts cannot be repainted.Control characters and bidi overrides are refused in every string, and evoke's own line prints before any reflex's.

Start

Install

One small native binary on macOS and Linux; Node beside it for reflexes written as JavaScript. The SDK is a package.

The CLI

Fetches the release built for your machine, checks it against the release's digests, and puts evoke in ~/.local/bin.

curl -fsSL https://evoke.build/install.sh | sh

The SDK

Node 24 or newer, ES modules, no dependencies; the core travels inside it as WebAssembly.

npm install @evoke-build/evoke

Then the first ten minutes: your key, the first-party reflexes, your first lesson. Every other way — mise, from source — is on the install page.
