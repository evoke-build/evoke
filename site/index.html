Software, by reflex.

evoke turns a sentence into a call of a small program — a reflex — chosen by a classifier that never generates text, gated by confidence, and run only when the call is safe enough to run.

One tool, three jobs

The same decisions, whether you type them, install them, or ship them inside your application.

A CLI you talk to

Say what you want. evoke shows the call it chose and its confidence, then runs, confirms, asks for what is missing, or abstains — and every line that needs you ends in the command that does it.

Saying things →

A package manager

A reflex is a directory in a git repository at a tag. evoke add owner/repo fetches it, lints its wording, pins it by content in evoke.lock, and never runs code to install it.

Installing reflexes →

A TypeScript SDK

The CLI's core, compiled to WebAssembly, inside your app: load a project, decide, run — with a typed decision for every outcome and a recorded adapter for tests that never touch the network.

Getting started →

The manifest is the product

The classifier is never trained. It answers closed questions — which of these? is this stated? — from a reflex's own wording, so the wording is the tuning. One line is documentation, tuning, test and customization at once.

The author owns the contract: what runs, the arguments, their options. Everything else is wording you may override in a file of your own, which no update ever touches. A value is always one of the author's options, one of your words, or a span of what you typed: a sentence can choose a call, never invent one.

Write a reflex in ten minutes → 
# hello/reflex.toml
reflex = 1

description = """
Say hello to someone.
A greeting with the name given, printed back."""
effect  = "read"
confirm = "Say hello to {who}?"
run     = "hello.mts"

[args.who]
ask  = "Who should be greeted?"
pick = "quoted"

[examples]
'say hello to "Ada"' = { who = "Ada" }

Install

One small native binary on macOS and Linux; Node beside it for reflexes written as JavaScript. The SDK is a package.

The CLI

Fetches the release built for your machine, checks it against the release's digests, and puts evoke in ~/.local/bin.

curl -fsSL https://evoke.build/install.sh | sh

The SDK

Node 24 or newer, ES modules, no dependencies; the core travels inside it as WebAssembly.

npm install @evoke-build/evoke

Then the first ten minutes: your key, the first-party reflexes, your first lesson. Every other way — mise, from source — is on the install page.
